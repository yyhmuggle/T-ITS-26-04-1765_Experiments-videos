# T-ITS-26-04-1765_Experiments-videos
Supplementary Videos for Manuscript T-ITS-26-04-1765
Title: Reinforcement Learning-Based Adaptive Finite-Time Path Tracking Control for Autonomous Vehicles with Uncertainties and Communication Constraints

Manuscript ID: T-ITS-26-04-1765 (submitted to IEEE Transactions on Intelligent Transportation Systems)

This repository contains the real-vehicle validation videos referred to in the revised manuscript and the response letter. The videos show the path tracking performance of the proposed controller and three benchmark controllers under single lane change (SLC) and double lane change (DLC) maneuvers.
